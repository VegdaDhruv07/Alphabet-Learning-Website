# 🔤 A to Z Alphabet Learning

A simple and interactive web project designed to help children learn
English alphabets and basic words in a fun and easy way.

## 📌 About the Project

This project helps children learn alphabets from **A to Z**.

The user enters a letter such as **A, B, C...** and clicks the
**Show 🚀** button.

The website then displays:

- 🔤 The selected alphabet
- 📚 10 words related to that alphabet
- 🔊 A Play button to hear the word
- 🎨 Colorful and child-friendly design

For example:

**A → A for Apple 🍎**

When the user clicks the **🔊 Play** button, the browser speaks:

**"A for Apple"**

## ✨ Features

- 🔤 A to Z alphabet learning
- 📚 10 words for each alphabet
- 🔊 Text-to-Speech voice feature
- 🚀 Interactive Show button
- 🎨 Colorful and attractive UI
- 🧒 Child-friendly design
- 📱 Responsive design
- ⌨️ Press Enter to show the alphabet
- 🔊 Individual Play button for each word

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Speech API
